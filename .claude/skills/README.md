# Skills

The skill folders in this directory (except any added separately for this
project) are copied from [obra/superpowers](https://github.com/obra/superpowers)
(MIT licensed — see `LICENSE-superpowers`), a general software-development
methodology skill set for Claude Code (planning, TDD, systematic debugging,
code review, git worktrees, etc.). They are unrelated to the job-autopilot
application itself; they're here so any Claude Code session that opens this
repository has them available, regardless of device.
